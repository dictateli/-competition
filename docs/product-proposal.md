# 合流 AI · 产品与比赛方案

## 一、产品定义

**一句话定位**：面向中小团队的 AI 协同办公工作流中枢，把会议、文档、任务和项目上下文连接起来，让 AI 从“被动回答”变成“主动推进工作”。

**目标用户**：10–200 人知识型团队，包括产品、研发、咨询、客户成功、运营和项目管理团队。

**核心价值**：
- 少开会、少整理、少追踪。
- 让每一次会议和文档处理直接产生下一步行动。
- 让组织经验自动沉淀，而不是散落在聊天记录和个人电脑中。

## 二、用户痛点

### 1. 信息碎片化

会议在会议系统、文档在网盘、任务在项目管理工具、沟通在即时通信中。员工每天都在多个系统间复制粘贴，上下文不断丢失。

### 2. AI 工具停留在”问答层“

通用 AI 助手可以总结一段文本，却不知道项目当前状态、谁负责什么、哪些结论已经发生变化，因此很难直接推动业务。

### 3. 会议和文档结束后，工作才刚开始

会议纪要需要人工整理，待办靠记忆分配，文档结论难以变成项目动作，导致“讨论很多、落地很少”。

### 4. 风险发现总是太晚

范围变更、资源冲突和依赖阻塞分散在不同记录里，往往等到周会或延期后才暴露。

## 三、产品主张

### 不做另一个聊天框

合流 AI 的核心对象不是聊天消息，而是**工作流**：

```text
输入 → 理解 → 建议 → 确认 → 执行 → 回流
```

### 三个关键差异

1. **上下文原生**：会议、文档、项目、任务共享同一份权限感知上下文。
2. **行动优先**：AI 输出不只是摘要，还包括负责人、截止时间、风险和下一步。
3. **主动协同**：AI 在后台持续监测变化，主动提醒，而不是等用户提问。

## 四、核心功能

### 1. AI 工作台

- 今日 AI 聚焦：按影响力、紧迫度和依赖关系排序。
- AI 信号雷达：发现范围变更、数据异常、资源冲突和项目延期风险。
- 工作流概览：自动处理事项、节省时间、按时交付率。
- 自然语言命令：输入目标后自动调用文档、会议、任务和知识库。

### 2. 智能会议纪要

- 实时语音识别与说话人分离。
- 自动生成摘要、决策、争议点和待办事项。
- 每个结论关联会议原声时间点。
- 待办一键分配负责人、截止时间和项目任务。
- 会议结束 1 分钟内生成可分享纪要。

### 3. AI 写作助手

- 基于项目数据、会议结论和历史文档生成初稿。
- 支持专业、克制、有温度等语气切换。
- 自动核验数据来源、日期和口径。
- 生成管理层摘要、周报、复盘、方案和客户材料。
- 引用可追溯，修改可撤销。

### 4. AI 项目管理

- 自然语言创建项目、任务和里程碑。
- 自动维护任务依赖和关键路径。
- 结合会议与文档变化预测延期风险。
- 团队负载分析，给出任务转交建议。
- 每日主动风险播报。

### 5. 智能文档分析

- 支持 PDF、DOCX、XLSX、TXT 等文档。
- 生成摘要、关键数据、风险条款和行动建议。
- 多文档对比与差异提取。
- RAG 问答，返回页码、段落和置信度。
- 自动写入知识库并继承原文件权限。

### 6. 知识中枢

- 会议、文档、项目和任务自动形成知识网络。
- 按组织、项目、客户和主题聚合经验。
- 权限感知检索，确保不同角色只看到授权内容。
- 高频问题沉淀为可复用模板和最佳实践。

### 7. 自动化工作流

- 用自然语言创建自动化流程。
- 支持定时、事件、Webhook 和人工触发。
- 可连接大模型、RAG、任务系统、企业微信、钉钉、飞书和邮件。
- 每次运行都有记录、状态、重试和成本信息。

## 五、关键用户旅程

### 旅程 A：会前、会中、会后闭环

1. AI 在会前读取项目、历史纪要和相关文档，生成会前简报。
2. 会中实时转写，自动识别关键决策和争议点。
3. 会后生成纪要，提取负责人、截止时间和行动项。
4. 用户确认后，行动项写入项目看板。
5. AI 持续跟踪任务状态，在风险出现前提醒。

**价值**：会议整理时间降低 90%+，待办遗漏率显著下降。

### 旅程 B：文档上传到知识沉淀

1. 用户拖入客户反馈、合同或行业报告。
2. 系统完成 OCR、解析、分段、向量化和权限标签。
3. AI 生成摘要、关键数据、风险与建议。
4. 用户可直接追问，所有回答附原文页码。
5. 文档进入知识网络，后续项目自动复用。

**价值**：文档阅读和分析时间降低 70%+。

### 旅程 C：自然语言创建自动化

用户输入：“每天检查高价值客户的活跃度，有下降风险就通知负责人并创建跟进任务。”

系统自动生成：

```text
客户活跃度监测 → AI 风险判断 → 创建任务 → 通知负责人
```

用户确认后即可运行，无需配置复杂节点。

## 六、AI 设计原则

1. **证据优先**：结论必须关联原始来源。
2. **权限一致**：AI 只能访问用户本人有权访问的数据。
3. **人机协同**：高风险动作必须人工确认。
4. **结构化输出**：任务、人员、时间、风险使用 JSON Schema 校验。
5. **可观测**：记录模型版本、Prompt 版本、耗时、成本和采纳率。
6. **持续学习**：用户对 AI 建议的采纳、修改和拒绝，用于优化 Prompt 与排序策略。

## 七、商业模式

### SaaS 订阅

- 免费版：3 人团队，每月 100 次 AI 任务。
- 专业版：39 元/人/月，完整会议、文档、项目和自动化能力。
- 企业版：按需报价，支持私有化、单点登录、审计和专属模型。

### 增值能力

- 行业知识库模板。
- 企业专属模型与私有知识训练。
- API / 工作流调用包。
- 部署实施与顾问服务。

## 八、北极星指标与衡量体系

### 北极星指标

**每周由 AI 推动并完成的有效业务动作数。**

### 一级指标

- 人均每周节省协同时间。
- AI 建议行动项采纳率。
- 会议纪要生成时间。
- 文档问答引用命中率。
- 风险提前发现率。
- 7 日与 30 日留存率。
- 付费团队数和人均付费金额。

### 目标值

| 指标 | 比赛演示目标 | 正式版目标 |
|---|---:|---:|
| 纪要生成时间 | < 1 分钟 | < 30 秒 |
| 文档分析耗时下降 | 70% | 80% |
| 行动项采纳率 | 35% | 50% |
| 高风险提前发现率 | 80% | 90% |
| 人均每周节省时间 | 6 小时 | 10 小时 |

## 九、差异化与竞争壁垒

### 相对通用 AI 助手

通用助手只有对话，合流 AI 拥有组织上下文、业务对象和执行工具。

### 相对会议纪要工具

会议工具只解决记录问题，合流 AI 将纪要直接转化为任务、项目变化和后续跟踪。

### 相对项目管理工具

项目工具需要人工更新，合流 AI 从会议和文档中自动感知变化，主动维护项目状态。

### 长期壁垒

1. 组织工作流数据与知识网络。
2. 行动采纳反馈形成的个性化排序模型。
3. 企业权限、审计和私有化部署能力。
4. 可连接的行业模板和自动化生态。

## 十、MVP 范围

比赛阶段优先完成以下闭环：

1. AI 会议转写与纪要生成。
2. 会议决策转任务。
3. 文档上传、摘要、风险识别与 RAG 问答。
4. AI 写作辅助。
5. 项目看板和风险雷达。
6. 一个可运行的自动化工作流。
7. 用户端 Web 的完整高保真交互原型。

### 暂不纳入首版

- 完整即时通信系统。
- 复杂 BPMN 编排。
- 全量第三方应用生态。
- 自研基础大模型。
- 移动端原生 App。

## 十一、实施路线图

### 第 1 阶段：原型验证（1–2 周）

- 完成 Vue 高保真原型和用户测试。
- 验证“会议 → 任务”和“文档 → 问答”两个核心价值。
- 建立基础 Java API 与 AI Gateway。

### 第 2 阶段：MVP（3–6 周）

- 完成会议、文档、任务、写作四个模块。
- 接入 ASR、LLM、Embedding 和向量数据库。
- 发布 10–20 人内部试用版。

### 第 3 阶段：团队版（2–3 个月）

- 项目风险、工作流自动化、通知与知识中枢。
- 权限、审计、计费和运营后台。
- 接入企业微信、钉钉和飞书。

### 第 4 阶段：企业版

- 私有化部署、专属模型、行业模板和开放 API。
- 建立生态合作与渠道体系。

## 十二、风险与应对

| 风险 | 应对 |
|---|---|
| AI 幻觉 | 强制引用、结构化校验、低置信度转人工 |
| 数据泄露 | 租户隔离、权限过滤、私有化选项、全量审计 |
| 模型成本过高 | 模型分级路由、缓存、上下文压缩、预算阈值 |
| 用户不信任 AI | 所有动作可确认、可修改、可撤销 |
| 接入成本高 | 优先做标准 API 和头部 SaaS 连接器 |
| 功能过多失焦 | 以“会议到行动”和“文档到知识”作为首批闭环 |

## 十三、比赛演示脚本

1. 在工作台展示 AI 自动排序的今日聚焦和项目风险。
2. 打开 AI 会议，展示实时转写、决策提取和行动项分配。
3. 将会议行动项一键写入项目看板。
4. 上传客户反馈文档，展示摘要、风险与 RAG 引用问答。
5. 用自然语言创建自动化工作流。
6. 最后回到工作台，展示 AI 主动推送风险并给出处理建议。

**演示记忆点**：用户不是“使用了 AI 工具”，而是“完成了一条原本需要两个小时的协同工作流”。
